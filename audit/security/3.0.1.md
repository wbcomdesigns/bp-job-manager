# Security audit - BP Job Manager 3.0.1 (vs v3.0.0)

Gate G1 (security-sweep.sh) and G3 (reviewed diff v3.0.0..HEAD). Static only; G2 role matrix not run here.

## Findings
None new. No CRITICAL, no HIGH.

## G1 delta vs v3.0.0
- ajax-nopriv CRITICAL (1 at v3.0.0): REMOVED. The `wp_ajax_nopriv_bpjm_load_more_jobs` / `bpjm_load_more_jobs` handler is gone; no JS or PHP reference remains.
- nonce-only-auth MEDIUM (1 at v3.0.0): gone with that handler.
- esc-sql-on-nonscalar MEDIUM (2): inherited, unchanged. `includes/class-bp-job-manager-function.php:182,247`; esc_sql() is applied to the WPML translations table name (a scalar), values go through prepare() placeholders.
- no-abspath-guard MEDIUM (7): inherited. All are index.php silence files, uninstall.php (guarded by WP_UNINSTALL_PLUGIN) and phpstan-bootstrap.php (dev only).

## G3 reviewed new request handlers (public/class-bp-job-manager-public.php)
- bpjm_handle_submission_actions (duplicate/continue/relist/renew): `wp_verify_nonce( 'job_manager_my_job_actions' )`, post type check, `job_manager_user_can_edit_job()`, own profile only, redirect via wp_safe_redirect. Safe.
- bpjm_handle_resume_relist: nonce `resume_manager_my_resume_actions` + `resume_manager_user_can_edit_resume()` + own profile. Safe.
- bpjm_notify_application_status: transition_post_status hook, adds a notification to the application's own `_candidate_user_id`; no request input. Safe.
- bpjm_mark_application_notifications_read: read-only GET, requires own profile and job authored by the viewer, marks only viewer's own notices. Safe.
- bpjm_redirect_old_applied_jobs / bpjm_keep_resume_save_in_profile: fixed internal redirects, no user-controlled target. Safe.
- bpjm_save_publish_activity (admin class): post-author-owned activity add/update keyed by item_id; no request input. Safe.
- Settings loader: now ignores a non-array option row (hardening).

## Scanner-visible but safe
- `$_GET` reads in bpjm_owner_sub_screen / bpjm_current_page: view state only, sanitised with sanitize_key/absint, gated on bp_is_my_profile().
